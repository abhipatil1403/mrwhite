# Mr. White

Mr. White — A modern local pass-the-phone social deduction party game built with Kotlin and Jetpack Compose.

## Overview

A classic social deduction game where players try to find out who among them are Undercovers or Mr. White.

- [x] Android project setup
- [x] Setup screen
